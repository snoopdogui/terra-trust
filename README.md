# Terra Trust

A proof-of-concept agricultural data trust for cocoa cooperatives, built on **synthetic data only**.

> Status: work in progress. This README is completed at the end of the build.

- Not deployed. No real users, farmers, cooperatives, buyers or coordinates.
- Not legal advice. No claim of compliance with the EU Deforestation Regulation or any other law.
- No backend, no API keys. State lives in memory and `localStorage`.

## Run it

```
npm install
npm run dev
npm test
npm run build
```
